## 安装

在 Claude Code 里先添加插件市场，再安装插件（`claude-plugins-official` 是官方市场，已经添加过的可以跳过第一步）：

```text
/plugin marketplace add jarrodwatts/claude-hud
/plugin install claude-hud@claude-hud

/plugin marketplace add anthropics/claude-plugins-official
/plugin install skill-creator@claude-plugins-official
/plugin install superpowers@claude-plugins-official

/plugin marketplace add dan323/easier-life-skills
/plugin install find-skills@easier-life-skills

/plugin marketplace add thedotmack/claude-mem
/plugin install claude-mem@thedotmack
```

装完后用 `/plugin` 查看安装状态。

## 安装后的配置

### claude-mem

装完要确认它的运行环境正常（依赖、后台服务）。环境有问题时按项目 README 修好再用。

### claude-hud

用 `/claude-hud:setup` 设为状态栏，再用 `/claude-hud:configure` 调整显示项。要求：

- **界面语言用英文**
- **显示周额度**（Weekly）

希望显示的内容：

| 行 | 显示项 |
|----|--------|
| 第 1 行 | 模型与推理档位、当前项目、Advisor 模型、git 分支、Claude Code 版本、会话时长、费用、订阅档位 |
| Context | 上下文占用百分比（进度条） |
| Usage | 5 小时额度占用百分比和重置倒计时 |
| Weekly | 周额度占用百分比和重置倒计时；另显示 Fable 模型单独的周额度 |
| Cache | 缓存状态 |
| Approx RAM | 内存占用 |
| 环境 | 加载的 CLAUDE.md 数、MCP 数 |
| 会话 | 开始时间、距上次回复多久 |
| Tokens | 总量及输入、输出、缓存的分项 |
| Compactions | 压缩次数 |
| 底栏 | 权限模式、运行中的子代理数 |
