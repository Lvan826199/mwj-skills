# MWJ Guide Site：新手指南网页

用户原话：「这种网页风格我很喜欢」（2026-11-18，一个内部群消息助手的指南页定稿后）。

**目标**：第一次来的人 3 分钟内知道「这是什么、我要准备什么、照哪几步做、出问题找谁」；老用户能直接找到升级步骤、指令和更新记录。

## 第 1 步：先收集内容，不先写样式

问清（能从项目里读到的自己读：README、部署文档、CHANGELOG、源码版本号）：

| 要什么 | 放到哪 |
|---|---|
| 工具名、一句话价值（≤ 20 字，带一个强调短语） | 首屏标题 |
| 2～3 行说明：做什么、不做什么、边界 | 首屏副标题 |
| 一个最典型的使用场景（3～5 条对话 / 步骤） | 首屏右侧示例卡 |
| 工作原理 3～4 步 + 2～3 种结果 | 「先认识它」 |
| 运行前提（系统、依赖、账号） | 「开始前，准备这几样」 |
| 上手步骤（≤ 6 步，每步一句话 + 可复制命令） | 编号步骤卡 + 进度勾选 |
| 日常指令 / 常用命令，按用途分组 | 「日常用法」 |
| 当前版本、升级步骤、CHANGELOG 路径 | 「升级」「更新记录」 |
| 要提供下载的文件 | 「下载」卡片 |
| 常见疑问 4～6 条（安全、隐私、权限、出问题找谁） | 「常见问题」 |

拿不到的不编，空着问用户。

## 第 2 步：用模板生成，样式不重写

- 样式：`assets/guide.css` 原样复制（Token 在 `:root`，深色三处：`[data-theme="dark"]`、`prefers-color-scheme` 且非 light），**不改配色和组件尺寸**；项目要换主色只改 `--blue` 系三个值。
- 页面骨架：`references/template.html`，按第 1 步的内容替换各段；段落可以删，不要加新的视觉样式。
- 生成脚本：`references/build_site.py`（读 `site.json`，复制文件、嵌入 CHANGELOG、生成 `index.html` + 文档阅读页 `view.html`）。用法、`site.json` 字段见脚本开头。
- Markdown 渲染用本地 `marked.min.js`（12.x，放 `assets/`），**不依赖外网 CDN**——内网用户可能上不了外网。

写法规矩（和样式一样重要）：

- 每段标题一句话说清，副标题 ≤ 2 行；卡片正文 ≤ 2 行。说不清就是内容没想清楚，回第 1 步。
- 命令一律放 `.cmd` 行带「复制」按钮；短指令放 `.tags code`（点击复制）。占位写法统一（如 `#编号`、`群名`），在段首说明怎么替换。
- 版本号只从一个地方读（源码 / package 元数据），页面里所有版本号由脚本替换，不手写。
- 进度勾选、主题选择存 `localStorage`，读写都包 try/catch，取不到时页面照常可用。
- 不放任何凭据；对外 / 公开部署时不放内网地址、同事姓名。

## 第 3 步：自托管（需要内网访问时）

见 `references/self-host.md`：`python3 -m http.server` 绑 `0.0.0.0`，macOS 用 LaunchAgent（登录后自启）或 LaunchDaemon（开机即起，需本人在桌面终端 sudo 安装），Windows 用计划任务。

- 站点输出目录不要放桌面 / 文稿：macOS 后台服务读不了这些目录（隐私保护）。
- 改端口前先 `lsof -iTCP:<端口> -sTCP:LISTEN` 看占用。
- 把「生成网页」挂到项目的发版 / 生成文档脚本末尾，发版即更新。

## 第 4 步：交付前自检

按 `ui-selfcheck` 截图（无头 Chrome 加 `--virtual-time-budget=3000`，否则 fetch 渲染的文档页截到「加载中」）：

- 桌面 1360 宽整页、手机 390 宽首屏、深色模式各一张，逐张看。
- **手机宽度别直接用 `--window-size=390,…` 截**：无头 Chrome 窗口最小约 485 宽，页面按 485 排版、截图只截左 390，看起来像横向溢出。有 playwright 用 `shot.py --viewports 390x844`；没有就套一层 `<iframe style="width:390px">` 截外层页面，或用 `document.documentElement.scrollWidth` 与 `clientWidth` 比较判断是否真溢出。
- 机器检查：首页、`view.html?f=…`、每个下载链接都 200；控制台无报错。
- 用内网地址（不是 127.0.0.1）再访问一次，确认别人能打开。
