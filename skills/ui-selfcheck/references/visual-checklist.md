# 看图清单

每张截图都要过一遍。看到问题就记下「截图路径 + 位置 + 现象」，修完重截。

## 1. 文字与数字

- [ ] 没有被截断、重叠，没有溢出容器；被截断的长文本有 title 或 tooltip
- [ ] 数字显示完整，不出现「1.2w」被挤成「1.」这种情况；金额、百分比的小数位统一
- [ ] 缺失值显示「—」或空态文案，**不能渲染成 0**
- [ ] 中文没有乱码，字体没有回退成宋体

## 2. 颜色与对比

- [ ] 文字和背景对比清楚：暗色背景上没有深灰字，下拉框、弹窗不会白底白字
- [ ] 状态色一致：成功、警告、错误、信息分别用同一套颜色
- [ ] 没有出现规范之外的硬编码颜色（MWJ 项目用 Token，见 mwj-design-system）

## 3. 布局与间距

- [ ] 对齐：同一行的元素垂直居中，表格的列对齐
- [ ] 间距统一，没有某一块特别挤或特别空
- [ ] 手机端撑满屏幕，两侧没有多余空隙，没有横向滚动条
- [ ] 桌面端首屏信息密度合理，栏高、内边距和同类页面一致
- [ ] 没有双左栏、重复标题、重复的面包屑

## 4. 状态

- [ ] 空态：有提示文案，必要时有引导操作
- [ ] 加载中：有骨架屏或 loading，不会一直闪
- [ ] 失败：显示一句能照着操作的中文提示，并且保留旧数据，不整页换成错误页
- [ ] 禁用：一眼能看出不可点

## 5. 导航与结构

- [ ] 当前页面的导航项高亮，面包屑正确
- [ ] 弹窗或抽屉打开后，遮罩、层级、关闭按钮都正常
- [ ] 新页面从导航能点进来

## 6. 图表

- [ ] 图表实际画出来了，不是一块空白
- [ ] 坐标轴、图例、tooltip 都在；dataZoom 滑块存在并可见
- [ ] 图表没有画出容器边界，数据点数量看起来合理
