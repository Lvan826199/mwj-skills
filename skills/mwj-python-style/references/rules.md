# 梦无矶项目约定审查清单

来源：MyProject 下各项目的归因文档、记忆和 AGENTS.md/CLAUDE.md，每条都是踩过的坑。括号里是建议级别。**项目自己的规则和本清单冲突时，以项目为准。**

**只审 diff 里新增或修改的行**；旧代码里存在的同类问题，最多在「补充建议」里提一句，不计入 P 级问题。标了「服务类项目」的条目，CLI 和库项目可以跳过。

## 一、注释与可追溯性

- **复杂逻辑注释用中文，写「为什么」**，不写「做了什么」。（P2）
- **超时、重试、阈值这类魔法常量，注释要写出处**：哪份回执第几项的实测值、哪天测的。改这类常量的 diff 如果没有出处，要追问。（P1）
  - 反例：把回执里的「约 17 秒返回」转述成「秒回」，超时砍到 6 秒，真机直接失败。
- 不提交无关或未使用的代码、调试 print、注释掉的大段旧代码。（P2）

## 二、设备与外部命令

- **subprocess 一律传参数列表，并设置 `timeout`**；禁止 `shell=True` 拼字符串（adb、iOS 工具、PowerShell 都一样）。（P1，拼接了用户输入的升为 P0）
- **ctypes 调 Win32**：返回句柄或指针的函数，必须声明 `restype`/`argtypes`（句柄用 `c_void_p`）。不声明时 64 位句柄会被截断，表现是「查不到」而不是报错。（P0）
- **改系统状态的操作要用独立手段回读验证**。回读不能和写入共用同一个常量或函数，否则常量写错，验证也跟着错（`SPDRP_UPPERFILTERS` 写成 0x12 的事故）。外部 exe 报「成功」不等于真的做成了。（P1）
- **杀进程要按项目路径或 pid 过滤**，禁止按进程名 `pkill`、`taskkill /IM` 一锅端，本机同时跑着多个项目。（P1）
- 同一件事不要在 bat 脚本和程序里各写一套逻辑。bat 只写 ASCII，开头加 `chcp 65001`；路径不要硬编码盘符或 `Program Files`。（P2）

## 三、对外契约与兼容

- **已发版下游在调用的协议、错误码、JSON 字段、CLI 参数：只能加，不能改名或删除。** 改默认值也算改契约，要问清楚「不带参数的那条命令现在走哪条路径」。（P0）
- 版本号只保留一个来源：运行时用 `importlib.metadata.version()` 读，或者有测试保证各处一致。新增手写的 `__version__` 要指出来。（P2）

## 四、错误处理

- 用 `raise ... from exc` 保留原异常链。（P2）
- 区分「目标没找到」和「基础设施故障」：没找到返回空结果，基础设施故障显式抛出。不要把故障吞掉变成空结果。（P1）
- 宽泛的 `except Exception: pass` 或只打日志后继续，会导致静默失败，要标出来。（P1）已经带理由注释的有意降级（如 `# noqa: BLE001 - 失败只告警不阻断`）不报。
- 错误提示改在用户最终看到的那一层。下游如果会把 message 换掉，上游加的提示等于白加，要有测试断言最终 message 的内容。（P2）

## 五、数据与并发

- **搬正在使用的数据库或文件**：复制 → 核对（行数）→ 切换 → 退役旧文件。不能直接 `shutil.move`，在 Windows 上会出现半复制状态。（P0）
- **长循环、网络同步不能一直开着写事务**，要按条提交，否则会长时间锁库。（P1）
- **同步或导入要有「空的不能覆盖有的」这条底线**，两个方向都要判断。（P0）
- **确定性计算（金额、收益、回测、日期）用代码算，不交给 AI**；回测起点必须按交易日取。（P1）
- 前端拉数据失败时，不能把已有数据替换成错误页。（P2，前后端联动时提出）

## 六、配置与凭据

- 配置用 pydantic-settings 加项目前缀；`.env.example` 入库，`.env` 放进 gitignore。（P2，服务类项目）
- **凭据（账号密码、API key、共享盘口令）不能出现在代码、测试、日志、提示词模板里**，只能从本机配置读取。（P0）
- 例外：项目规则里明确写了「有意保留」的（例如私有仓库里经过评估的配置快照），按项目规则处理，不再当作泄露报告。

## 七、测试

- **测试要走真实入口**（`cli.main(argv)`、真实路由），不能只测被测函数本身。（P1）
- **假服务只允许回执里真实出现过的设备行为**，遇到没见过的用法要当场失败。路由、超时预算、连接寿命这三层，单元测试抓不到。（P1）
- 同一功能有两条调用路径（例如 CLI 和 sidecar），两条都要测。（P1）
- pytest 标记：`unit` / `integration` / `smoke`；真机测试和真模型测试默认跳过。（P2）集成测试不能写进真实库，测试库名以 `_test` 结尾。（P1，服务类项目）
- 覆盖率只升不降。（P3）

## 八、界面相关的 Python 侧

- 新增页面或接口时，导航、权限的注册是否齐全（Vue 侧由 ui-selfcheck 检查，这里只看后端权限）。（P2）
